# Contributing

Issues and focused pull requests are welcome.

1. Do not include real budget, account, transaction, token, hostname, or
   infrastructure data.
2. Add or update tests for behavior changes.
3. Run the test, lint, type-check, and build commands from the README.
4. Keep write operations explicitly gated and preserve read-only defaults.

By contributing, you agree that your contribution is licensed under the MIT
license used by this repository.
