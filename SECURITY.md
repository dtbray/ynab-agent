# Security policy

Please do not open a public issue for a suspected vulnerability or accidental
credential exposure.

Report security problems through
[GitHub private vulnerability reporting](https://github.com/dtbray/ynab-agent/security/advisories/new).
Include the affected version, reproduction steps, and impact when possible.

Never attach real YNAB tokens, OAuth refresh tokens, budget exports, database
files, or account data to a report. Use synthetic examples.
